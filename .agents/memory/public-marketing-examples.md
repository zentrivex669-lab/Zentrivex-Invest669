name: Public marketing and access rules
description: Zentrivex rules for public marketing claims, sample identities, and admin portal access.
---

Do not show fabricated customer testimonials or real-looking sample names as public endorsements. If the testimonials are not genuine and authorized, remove the testimonial section instead of merely changing the displayed names.

**Why:** The user asked to remove a fabricated Lagos testimonial and sample names such as John Doe.

**How to apply:** Before changing public marketing copy or forms, check for fictional customer stories and example personal names; use neutral field instructions instead of invented identities.

Do not link to the admin sign-in from public pages. Keep `/admin/login` available for direct access and preserve separate user sign-in routes.

**Why:** The user asked to remove public admin-login links while keeping direct admin access at `/admin/login`.

**How to apply:** When editing public navigation or footers, omit the admin route; do not remove or rename the direct route or combine it with user authentication.

Keep public About, Terms, and homepage footer copy free of investment-risk warnings and return disclaimers. Retain transaction and account-security notices that protect users during account or payment actions.

**Why:** The user asked to remove public investment-risk copy while keeping operational transaction and security feedback.

**How to apply:** Do not reintroduce investment-loss or return-not-guaranteed copy in public pages or footer settings; preserve unrelated legal clauses and transaction-safety notices.
